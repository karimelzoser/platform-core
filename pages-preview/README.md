# GitHub Pages preview

This directory is a static, deterministic browser preview of PRENEURA Platform.

It is intentionally separate from the production Next/Nest/PostgreSQL/Keycloak/Temporal runtime. GitHub Pages cannot execute those server-side components. The preview exists so product navigation, information architecture, responsive behavior, LTR/RTL direction, and module-level UX can be reviewed from a stable public URL while real backend behavior remains verified in GitHub Actions.

Do not treat demo badges, sample metrics, or local-browser state as production data or production-provider evidence.
